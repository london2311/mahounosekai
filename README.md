# マホウノセカイ — 灯火の魔法使い

ブラウザで遊べる、魔法使いのオープンワールドRPGです（three.js 製・インストール不要）。
GitHub Pages で公開すると、スマホでもPCでもそのまま遊べます。

## あそび方

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 | WASD / 矢印キー（Shiftで走る） | 画面の左側をなぞる |
| 視点 | 右ドラッグ（左ドラッグは詠唱しながら視点移動） | 画面の右側をなぞる／2本指でズーム |
| 魔法 | 左クリック長押し or F長押しで魔力を込め、離して放つ | 「詠唱」ボタン長押し→離す |
| 属性 | 1 炎 / 2 氷 / 3 雷 | 炎・氷・雷ボタン |
| オートフォーカス | Q で ON/OFF、Tab で狙いを切り替え | ◎ボタン（狙い中は押すと切り替え） |
| 話す・調べる | E | 「話す」ボタン |
| 地図・転移 | M | 地図ボタン |
| メニュー | I / Esc | メニューボタン |

## 魔法とオーラ

- 使えるのは炎「ファイア」・氷「フロスト」・雷「スパーク」の弱い魔法だけ。
- 魔力の最大量＝**オーラ量**。オーラは主人公のまわりに光として見え、量が増えるほど大きくなります（上限なし）。
- 魔法は「込めた魔力」で威力も見た目の大きさも決まります。長押しで込め続ければ、弱い魔法でも天変地異級に。
- オーラはレベルアップ（1レベルごとに×1.12）、世界各地に隠された「魔力の結晶」（17個・1つごとに×1.08）、森の長老の祝福で増えていきます。
- 炎は燃焼、氷は鈍足・凍結、雷はしびれと連鎖。魔物ごとに弱点・耐性があります。

## 世界

はじまりの丘（出発地点）／風見の村／王都アルディア（城・城下町）／魔法学院／交易都市ベルカ／
灼熱の砂漠とオアシスの集落サラ／霊峰山脈と山道・霧の峠／帝国の関所／帝都ガルヴァス（宮殿）／
古代遺跡と地下迷宮（ダンジョン）／竜の峰／迷いの森と森の集落リーフェ／妖精の泉／嘆きの沼地と魔女の庵／
鏡の湖と川／港町マリナ／南の海と月影島（神社・灯台）

住民は100人以上。一人ひとりに名前・性格・台詞があり、出会った人はメニューの「人物帳」に記録されます。
武器屋・道具屋・宿屋（泊まると記録）・船頭・転移石などがあります。

## 物語（第一章「灯火の魔法使い」）

千年前、大魔導士アルマは「虚無の王」を三つの星晶で封じた。その封印が揺らぎはじめた時代、
記憶を失った見習い魔法使いルカは、はじまりの丘の焚き火のそばで目を覚ます——。
メインクエスト14段階と、住民からの依頼（サブクエスト）が遊べます。

## ファイル構成

```
index.html      画面（HUD・ボタン・会話ウィンドウ）とスタイル
js/core.js      設定・乱数・描画の準備・形をまとめる道具
js/world.js     地形（山・川・湖・海・道）と地名、当たり判定
js/build.js     町・城・遺跡・地下迷宮などの建物
js/actors.js    人の姿と主人公
js/magic.js     魔法・オーラ・オートフォーカス・演出
js/enemies.js   魔物の種類・出現場所・動き
js/npcs.js      住民（名前・人格・台詞）と動き
js/story.js     物語・クエスト・道具・装備・店・記録
js/ui.js        画面表示（会話・店・地図・ミニマップ）
js/sound.js     効果音
js/main.js      入力・カメラ・ゲームの進行
```

ブラウザのコンソールから `game` で中身に触れます（例：`game.warpTo('empire')`）。

## GitHub Pages で公開する

リポジトリの **Settings → Pages** で「Deploy from a branch」を選び、Branch を `main`・フォルダを `/ (root)` にして保存します。
数分後に `https://<ユーザー名>.github.io/mahounosekai/` で遊べるようになります。
