# 還魂の大魔導 — 星墜としの帰還

ブラウザで遊べる、魔法使いのオープンワールド・アクションRPGです（three.js 製・インストール不要）。
GitHub Pages で公開すると、スマホでもPCでもそのまま遊べます。

> ⚠ 戦争による流血・遺体・部位欠損・捕虜への暴行など、残酷な描写が含まれます。

## 魔法 — 地形を変えるほどの最高位魔法

| 属性 | 魔法 | 効果 |
| --- | --- | --- |
| 炎 | 煉獄 | 巨大な火球。着弾点を焼き尽くし、兵を吹き飛ばす |
| 水 | 大海嘯 | 前方へ押し寄せる大津波。軍勢をまとめて押し流す |
| 氷 | 永久凍土 | 三本の氷槍。着弾点を凍てつかせ、兵を砕く |
| 雷 | 天雷 | 天から落ちる雷。周囲の敵へ連鎖する |
| 重力 | 崩星 | 黒い星で敵を引き寄せ、押し潰す。大地が陥没する |
| 樹木 | 千年樹 | 地中から巨大な根と棘が突き出し、敵を貫く |
| 光 | 天照 | 天から光の柱。敵を跡形もなく焼き払う |
| 闇 | 深淵 | 地に開く深淵。敵を呑み込む |

- **守護の刻印**：主人公は常にこの術を使っているため、魔法は**王国の人・建物には一切当たりません**。傷つくのは帝国の兵と、帝国の建物（天幕・攻城塔・砦・帝都の家や城壁）だけ。大地のえぐれ（クレーター）も敵地にしか残りません。
- 魔力の最大量＝**オーラ量**（はじめから 50,000）。長押しで込めた魔力が威力と大きさになり、上限はありません。レベルアップや「魔力の結晶」でさらに増えます。
- 数千人の帝国軍は一人ひとりが動きます。魔法で薙ぎ払うと、焼け焦げ、凍って砕け、押し潰され、吹き飛び、血の跡と亡骸が残ります。

## 演出と音

- 炎：白く光る芯と揺らめく炎の尾。着弾すると火球がふくらみ、黒煙へと冷えていき、火の粉が飛び、地面に焦げ跡が残る
- 氷：冷気をまとった氷の刃。着弾点から氷の結晶が突き出し、しばらくすると砕け散って冷気が広がる
- 雷：枝分かれしてちらつく稲妻と画面の閃光。着弾点で放電が走り、火花と焦げ跡が残る
- 音楽は場面ごとに作曲したものをブラウザの中で演奏します（タイトル／鎮魂歌／草原／町／地下迷宮／戦闘／ボス）。音声ファイルは使っていません
- 効果音：詠唱のうなり（込めるほど高くなる）、爆発・氷の砕ける音・雷鳴、命中、撃破、ジャンプ、転移など

## 世界

はじまりの丘／風見の村／王都アルディア（十万人が暮らす城下町と城）／魔法学院／交易都市ベルカ／
灼熱の砂漠とオアシスの集落サラ／霊峰山脈と山道・霧の峠／帝国の関所／帝都ガルヴァス（宮殿）／
古代遺跡と地下迷宮（ダンジョン）／竜の峰／迷いの森と森の集落リーフェ／妖精の泉／嘆きの沼地と魔女の庵／
鏡の湖と川／港町マリナ／南の海と月影島（神社・灯台）

住民は100人以上。一人ひとりに名前・性格・台詞があり、出会った人はメニューの「人物帳」に記録されます。
武器屋・道具屋・宿屋（泊まると記録）・船頭・転移石などがあります。

## 人と戦場の表現

- 人は骨格つきの滑らかな体（頭・首・胴・上腕・前腕・手・もも・すね・足）で、顔（目・眉・鼻・口・耳）や髪型、鎧や外套まで作り分けています。歩く・ひざまずく・祈る・泣き崩れるといった姿勢をとり、泣く人の目からは涙がこぼれます。
- 数千人の兵も同じ人体を使い、一人ひとりが手足を振って行進します。
- 魔法を受けた兵は、首・腕・脚がちぎれ飛び、切り口から血が噴き出し、胴だけになった亡骸や首のない亡骸が残ります。

## 物語

五年前に病で死んだ王国魔法師団長、“星墜とし”のレグルス・アルスター。
三十倍の兵を持つガルヴァス帝国に攻め込まれ、十万の民が暮らす王都アルディアは陥落寸前。
城下では逃げ遅れた人々が嬲られ、城の中まで帝国兵がなだれ込んでいる。
王女セシリアは己の命と引き換えに禁術「還魂の儀」を行い、レグルスを呼び戻した——。

- **序章「還魂」**：城内の帝国兵を掃討し、捕虜を嬲る第十将グラウスを討つ → 中庭で最後の防衛線を張る側近（ヴォルク・ユキナ・ライガ）を救う → 城下で嬲られている人々を救い出す → 城外に待機する三千の軍勢と第九将を殲滅 → 死者を弔い、復讐を誓う
- **第一章「反撃の狼煙」**：占領された風見の村・魔法学院・古代遺跡を奪い返し、五年前の「病死」の真相を知る
- **第二章「帝国侵攻」**：霧の峠の砦、関所、竜の峰、帝都ガルヴァスへ。帝国十将と、すべての黒幕に報いを受けさせる

帝国十将（部下は総勢5万）はそれぞれ姿も戦い方も違い、出会ったとき・倒したときに言葉を交わします。
倒した十将の数、討ち取った帝国兵の数、救った人の数はメニューの「目的」で確認できます。

### 表現について

戦争の悲惨さと、そこからの反撃を描くため、流血・遺体・部位欠損・捕虜への暴行（殴打・嘲り）などの残酷な描写を含みます。
性的な暴力の描写、子どもが傷つけられる場面の直接的な描写は含みません。

## ファイル構成

```
index.html      画面（HUD・ボタン・会話ウィンドウ）とスタイル
js/core.js      設定・乱数・描画の準備・形をまとめる道具
js/world.js     地形（山・川・湖・海・道）と地名、当たり判定
js/build.js     町・城・遺跡・地下迷宮などの建物
js/body.js      骨格つきの人体（顔・手足・姿勢・涙・大軍勢用の体・亡骸とちぎれた部位）
js/actors.js    主人公（歩く・飛ぶ・詠唱）
js/magic.js     魔法・オーラ・オートフォーカス・演出（炎・氷・雷）
js/spells.js    水・重力・樹木・光・闇の魔法
js/army.js      帝国の大軍勢・壊せる建物・亡骸と血の跡
js/capital.js   包囲された王都アルディア（城・城下町・帝国軍の陣・捕らわれた人々）
js/enemies.js   魔物の種類・出現場所・動き
js/npcs.js      住民（名前・人格・台詞）と動き、物語に合わせた居場所
js/story.js     物語・帝国十将・クエスト・道具・装備・店・記録
js/cutscene.js  プロローグなどの演出（語り・カメラ）
js/ui.js        画面表示（会話・店・地図・ミニマップ）
js/sound.js     音楽と効果音
js/main.js      入力・カメラ・ゲームの進行
```

ブラウザのコンソールから `game` で中身に触れます（例：`game.warpTo('empire')`）。

## GitHub Pages で公開する

リポジトリの **Settings → Pages** で「Deploy from a branch」を選び、Branch を `main`・フォルダを `/ (root)` にして保存します。
数分後に `https://<ユーザー名>.github.io/mahounosekai/` で遊べるようになります。
